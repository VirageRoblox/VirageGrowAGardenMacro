# Virage's Grow A Garden Macro

An updated free version of macro for the Roblox game "Grow a Garden"

Current version of this fork: Pet Mutation Update

Tips if you are having issues with the macro:

 - Try exit all other application that uses WebView2 before running the macro, could be browsers, discord, spotify, etc. 

 - Try running the macro as administrator.

 - If the first sequence of tasks run smoothly, your macro should be fine for afk.

 - Strictly follow the instructions in the original repo (Turn off shift lock, camera mode and movement to default, UI navigation to on, put recall wrench in 2nd slot of hotbar, fill hotbar with 8-10 items...)

For detailed info, please head to the original repo of the macro's creator
